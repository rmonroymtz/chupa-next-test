# Phase 5 storefront — basic account area on Next

Objective: Next serves the basic account pages (`/my-account`, profile, address book, support, the legacy aliases and the reset-password link target) on top of the phase 4 session.
Branch: `feat/phase-5-account` (from `main`). Delivery: `ask-on-risk`, stacked PRs (as phase 4). Runner: `pnpm typecheck && pnpm lint && pnpm test`,
`pnpm test:integration`, `pnpm build`, `pnpm test:e2e --project local`.

## Specs

- S1 Scope (user): "vamos con el que sigue" after the migration map. Phase 5 = the basic account: `/my-account`, account information (view and edit), address book (list, new, edit), support, the five legacy aliases and `/customer/account/createPassword`. Orders, quotes, saved cards, billing/invoices, checkout and the `/kueski/*` returns stay on the PWA.
- S2 Auth guard (legacy `AuthRoute`, `redirectTo="/sign-in"`): every account page needs a session. A guest is sent to `/sign-in`; the token lives in the PWA `localStorage`, so the guard runs in the browser. Next keeps the return url in `?from=` (the legacy stored `state.from` but nothing read it).
- S3 `/my-account` (legacy `Dashboard`): title "Mi cuenta", heading "MI CUENTA", greeting "Hola, {firstname lastname}" (fallback "Usuario", initials "U"), avatar = `social_profile_photo` or initials, intro "Desde aquí puedes gestionar tu perfil, ver el estado de tus pedidos, y mantener tus direcciones al día.". Data: `customer { firstname lastname social_profile_photo }`.
- S4 The six cards, in this order, with these links and texts:
  - "Órdenes y facturación" → `/my-account/order-history`: "Sigue el estado de tus pedidos, desde la preparación hasta la entrega, y revisa todos los detalles de tus compras."
  - "Cotizaciones" → `/my-account/quotes`: "Consulta aquí todas las cotizaciones que has generado. Recuerda que cada cotización es válida por 5 días."
  - "Direcciones" → `/my-account/address-book`: "Administra fácilmente todas tus direcciones guardadas para envíos."
  - "Tarjetas" → `/my-account/saved-payments`: "Agregar, editar o eliminar tarjetas de crédito y débito, y otras opciones disponibles."
  - "Atención al cliente" → `/my-account/support`: "¿Tienes alguna duda o necesitas ayuda? Usa esta sección para contactar a nuestro equipo."
  - "Perfil" → `/my-account/account-information`: "Puedes revisar y editar tus datos personales esenciales, actualizar tu contraseña y activar la Verificación en 2 pasos."
- S5 Breadcrumb from the url path. Labels: my-account "Mi cuenta", order-history "Mis órdenes", address-book "Mis direcciones", account-information "Mi perfil", edit-account-information "Editar datos", new "Agregar dirección", edit "Editar dirección", quotes "Mis cotizaciones", support "Atención a clientes", saved-payments "Mis tarjetas", billing-address "Datos de facturación". Numeric segments hidden. With `?callbackUrl=` the previous crumb links there.
- S6 Aliases (legacy `DashboardRedirect`): `/order-history`, `/account-information`, `/address-book`, `/saved-payments`, `/quotes` redirect to `/my-account` + the same path. Old emails and bookmarks use them. (Legacy dropped the query string; Next keeps it.)
- S7 `/my-account/account-information` (legacy view): title "Mi perfil", heading "MI PERFIL", avatar or initials, full name (first + middle + last), "Correo electrónico", "Teléfono" as "+52 {n}" only when a phone exists, button "EDITAR DATOS" → `/my-account/edit-account-information`. Load error: "Algo salió mal. Por favor, actualiza la página e inténtalo de nuevo.".
- S8 `/my-account/edit-account-information` (legacy edit): fields `firstname` "Nombre" and `lastname` "Apellido" (required), `email` "Correo electrónico" (required) with the hint "Para cambiar tu correo deberás confirmar tu contraseña en la sección Seguridad.", `phone_number` "Teléfono" with the prefix "🇲🇽 +52", numeric, max 10, placeholder "10 dígitos". Section "Seguridad": "Contraseña ••••••••" + button "Cambiar contraseña"; revealed fields "Contraseña actual" (required) and "Nueva contraseña", link "Cancelar cambio de contraseña", toggles "Ver contraseña" / "Ocultar contraseña". New password rules: required, at least 8 characters, at least 3 of lower/upper/digit/special, different from the current one. Messages: "Este campo es obligatorio", "Debe contener al menos {value} caracter(es).", "Una contraseña debe contener al menos 3 de los siguientes: minúsculas, mayúsculas, dígitos, caracteres especiales.", "{value} debe ser diferente". Buttons "Guardar cambios" / "Guardando...", "Cancelar".
- S9 Profile save (legacy order): phone changed → `updateCustomer(input:{phone_number})`; email, first or last name changed → `updateCustomer(input:{email,firstname,lastname,password})` (the current password is always sent); `password` and `newPassword` present → `changeCustomerPassword(currentPassword,newPassword)` with reCAPTCHA `CUSTOMER_EDIT`. After success go to `/my-account/account-information`; no toast, no token refresh, no sign-out. Server errors in a form error box.
- S10 `/my-account/address-book` (legacy list): heading "MIS DIRECCIONES", cards sorted with `default_shipping` first, "Agregar dirección" button. Card: badge "Principal" for the default shipping address, name, street lines, number (`custom_field_2`), colonia (`custom_field_3`), municipio (`custom_field_4`), "city, region", postcode, phone, edit and trash buttons (trash hidden on the default shipping address); delete flips the card to "Eliminar" / "Cancelar" and runs `deleteCustomerAddress(id:Int!)`. Empty state: "¡Aún no tienes direcciones guardadas!" / "Registra aquí tus direcciones de envío y facturación favoritas. De esta forma, tus próximas compras serán mucho más rápidas y sencillas." / button "Agregar dirección". The "DIRECCIONES DE FACTURACIÓN" section (RFC, CFDI) belongs to the billing phase and is not built here.
- S11 `/my-account/address-book/new` and `/edit/:id`: titles "Nueva dirección" or "Agregar dirección" (new), "Editar dirección" (edit); buttons "Cancelar" and "Guardar". `createCustomerAddress(input)` / `updateCustomerAddress(id, input)`; `middlename` defaults to `''`, empty street lines are dropped, `custom_attributes` go as `[{attribute_code,value}]`; both return to `/my-account/address-book`. Country defaults to `MX`. Groups "Destinatario" (`firstname`, `lastname`, `custom_field_1`, `telephone`) and "Dirección" (`postcode` 5 digits, region, `country_id`, `custom_field_2` Número with a "Sin número" checkbox that stores `S/N`, `custom_field_3`, `custom_field_4`); `region` and `postcode` always required. The field list comes from `storeConfig.amasty_checkout_manage_checkout_fields`. Google Places autocomplete ("Calle y número", "Buscando dirección...", "No encontramos resultados para la dirección ingresada.") and the `getSepomexData` lookup fill the Mexico fields.
- S12 `/my-account/support` (legacy `Contact`): a static page, heading "ATENCIÓN A CLIENTES", no form. Cards "TELÉFONO" ((+52) 664 311 9682; "Lunes a sábados: 09:00hs a 18:00hs"; "Domingos: 10:00hs a 16:00hs"), "WHATSAPP" (same number, link `https://wa.me/526643119682` "Click para ir a Whatsapp web", QR image) and "CHAT EN LÍNEA" (buttons "Chupaprecios" and "Click para abrir el chat", both `window.ChupaChat?.open()`).
- S13 `/customer/account/createPassword` (Venia `ResetPassword`): reads only `?token=`; without it "Uh oh, algo salió mal. Verifica el enlace o inténtalo de nuevo.". Heading "Restablecer contraseña", text "Por favor ingresa tu dirección de correo electrónico y una nueva contraseña.", fields email (required) and "Nueva contraseña" (required only), reCAPTCHA `CUSTOMER_FORGOT_PASSWORD`, button "Guardar contraseña", mutation `resetPassword(email, resetPasswordToken, newPassword)`. Success replaces the form with "Tu nueva contraseña ha sido guardada. Por favor usa esta contraseña para iniciar sesión en tu Cuenta." (no redirect). The exact path is baked into the Magento email, so Next must serve it.
- S14 Edge (T5): new exact rules above the PWA default for the migrated urls (`/my-account`, `/my-account/account-information`, `/my-account/edit-account-information`, `/my-account/address-book`, `/my-account/address-book/new`, `/my-account/address-book/edit/:id`, `/my-account/support`, the five aliases, `/customer/account/createPassword`) in `docs/routing/phase-5.md`; the rest of `/my-account/*` stays on the PWA.
